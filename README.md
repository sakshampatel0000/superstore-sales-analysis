# 📊 Superstore Sales Analysis

## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on the Superstore Sales dataset using Python.

The objective of this project is to analyze sales performance, profit trends, customer segments, shipping modes, and regional performance through various data visualizations.

---

## 🎯 Project Objectives

- Understand overall sales performance
- Analyze profit across different categories
- Identify high-performing regions
- Compare customer segments
- Analyze shipping modes
- Study sales distribution
- Explore the relationship between Sales and Profit
- Generate business insights

---

## 📈 Key Business Insights

- Technology generated the highest sales.
- Profit varied across different categories.
- Standard Class was the most frequently used shipping mode.
- Most orders had relatively low sales values.
- Higher sales do not always generate higher profit.
- Higher discounts generally reduce profitability.
- A few high-value orders contributed significantly to total sales.
